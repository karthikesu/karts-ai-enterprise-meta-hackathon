Truth boundary: the screen demo uses dummy shops and deterministic booking state. The integrated Baseten results below came from the recorded app-path batch. Replaying this page makes no API call and must not be described as live.

Architecture

1. Customer messageTamil, Malay or English dummy shop enquiry.
2. Language modelMuse Spark Open receives fake inventory and booking state in the full prompt.
3. Booking engineDeterministic code owns availability and saves dummy booking records before confirmation.
4. GuardrailUnsupported affirmative booking claims are blocked; truthful negative statements are allowed.
